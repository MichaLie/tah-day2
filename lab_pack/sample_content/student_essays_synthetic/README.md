# Synthetic Student Essays — for Track 3

**These six essays are entirely fabricated for this course.** No real student wrote them; no real person is described. They exist so you can practise summarization, theme extraction, and feedback drafting **without ever touching real student data**.

Topic (matches `sample_assignment.md`): *"Choose one digital technology that has changed higher education in the last decade. Argue whether its overall effect has been positive or negative, using evidence."*

The set is deliberately varied — different technologies, different quality levels, and a few **recurring patterns** planted on purpose (over-claiming without evidence; confusing correlation with causation; a fabricated-looking statistic; strong vs. weak use of sources) so that theme extraction and misconception-spotting have something real to find.

Files: `student_A.md` … `student_F.md`. Students are identified by letter only — practise the habit even though the data is synthetic.
