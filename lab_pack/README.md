## Access
- The **new ChatGPT desktop app → Codex mode** is the default for every track. ChatGPT Work is not required for this lab.
- Official installer: <https://chatgpt.com/download/>
- Work from a safe folder: create a new, empty folder on your Desktop, copy in only green files, open the ChatGPT desktop app, switch to Codex mode, choose that folder as the project folder, and ask for a plan first.
- Approve file changes only inside that safe folder.
- Fallback: open `PLAIN_CHAT_FALLBACK.md` if setup stalls; preserve the brief and verification steps and copy outputs manually.
