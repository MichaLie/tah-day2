# Quiz maker

Turn a provided source (glossary, notes, question list) into one self-contained `index.html` quiz.

## Steps
1. Read the source file the user names. Use **only** that content — do not add outside facts.
2. Propose a short plan: how many questions, what format (multiple choice / true-false / short answer), based on the source. Wait for approval.
3. Build a single `index.html`:
   - Everything needed must be inside one file. No hidden internet connections, outside scripts, outside fonts, or trackers.
   - For each question: the question, options, the correct answer, and a **one-line explanation** drawn from the source.
   - Show a score summary at the end listing which were wrong and why.
   - Keyboard-accessible (tab/enter/arrows), high-contrast, works on a phone.
4. Add a footer: "Draft quiz — generated by an AI agent from [source]; answers instructor-verified before use."

## Rules
- Every correct answer must be traceable to the source. If the source is ambiguous on a point, don't make a question of it — list it for the instructor instead.
- No data collection, no logins, no network calls.
- Stop and ask if the source contains anything that looks like real student data.

## Check before finishing
- Do all correct answers actually match the source?
- Does it open and run with no internet connection?
- Can you complete it using only the keyboard?
